Maneuvering Dynamics

20°/20° Zigzag Maneuver

Nonlinear 3-DOF ship manoeuvring model — Abkowitz / Norrbin formulation

The zigzag test is a canonical IMO trial that characterises a ship's course-keeping and initial-turning ability. The rudder is stepped to a fixed angle and reversed each time the heading crosses the same magnitude in the opposite sense, producing a repeating S-shaped heading trace.

3-DOF Equations of Motion
$$ \begin{aligned} (m - X_{\dot u})\,\dot u &= X(u, v, r, \delta) \\ (m - Y_{\dot v})\,\dot v + (m x_G - Y_{\dot r})\,\dot r &= Y(u, v, r, \delta) \\ (m x_G - N_{\dot v})\,\dot v + (I_z - N_{\dot r})\,\dot r &= N(u, v, r, \delta) \end{aligned} $$

Forces $X$, $Y$ and moment $N$ expand as polynomials in $u, v, r$ and rudder $\delta$, with coefficients identified from PMM tests.

Key Output Metric

The maximum absolute heading excursion is tracked across the run as the headline manoeuvring indicator; overshoot angles can be read directly off the heading-vs-time plot.

Numerical Integration

The state vector $x = [u, v, r, x_E, y_E, \psi, \delta]$ is advanced with explicit Euler at timestep $h$. Rudder is held at zero until $t = t_0$, then commanded to $\pm 20^\circ$ and reversed whenever the heading reaches $\pm 20^\circ$, for the remainder of the run $T$.

Simulation Workflow

How the Visualiser Works

Real trajectory · time-compressed playback

Inputs Hydrodynamic Profile

Edit hull mass, inertia and the full Abkowitz coefficient set on the left. Operational sliders set initial speed $U_0$, first rudder application time $t_0$ and total run time $T$.

Solver Django Backend

POSTs the full parameter set to the Django integrator, which returns the $t$, $u$, $v$, $r$, $x$, $y$, $\psi$, $U$, $\delta$ time series plus the maximum yaw metric.

3D View Time-Compressed Replay

The 3D pane draws the real trajectory but normalises playback to a 5-second loop so the manoeuvre stays visible regardless of run length.
