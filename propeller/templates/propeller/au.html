Propeller Design Standard

Japanese AU-Series Analysis

Open-water performance is obtained from a four-parameter polynomial regression. The blade section geometry is generated from the Table 6.8 offset dataset.

The solver evaluates the advance coefficient \(J\), thrust coefficient \(K_T\), torque coefficient \(K_Q\), and open-water efficiency \(\eta_0\) throughout the selected operating range.

Advance Coefficient
\[ J = \frac{V_A}{nD} \]

\(V_A\) is the propeller advance velocity, \(n\) is the rotational frequency in revolutions per second, and \(D\) is the propeller diameter.

Dimensionless Thrust and Torque Coefficients
\[ K_T = \frac{T}{\rho n^2 D^4} \]
\[ K_Q = \frac{Q}{\rho n^2 D^5} \]

Here, \(T\) represents propeller thrust, \(Q\) represents shaft torque, and \(\rho\) is the fluid density.

AU-Series Thrust Polynomial
\[ K_T = \sum_{i=1}^{N_T} C_{T,i} J^{s_i} \left(\frac{P}{D}\right)^{t_i} \left(\frac{A_E}{A_0}\right)^{u_i} Z^{v_i} \]

The polynomial depends on advance coefficient \(J\), pitch ratio \(P/D\), expanded area ratio \(A_E/A_0\), and blade count \(Z\).

AU-Series Scaled Torque Polynomial
\[ 10K_Q = \sum_{i=1}^{N_Q} C_{Q,i} J^{s_i} \left(\frac{P}{D}\right)^{t_i} \left(\frac{A_E}{A_0}\right)^{u_i} Z^{v_i} \]

The analytical chart displays the scaled torque ordinate \(10K_Q\). The physical torque coefficient is therefore \(K_Q=(10K_Q)/10\).

Open-Water Efficiency
\[ \eta_0 = \frac{J K_T}{2\pi K_Q} = \frac{5J K_T}{\pi(10K_Q)} \]

The first expression uses \(K_Q\), while the equivalent second expression can be used directly when the solver returns the scaled value \(10K_Q\).

Non-Dimensional Section Station
\[ \frac{r}{R} = \frac{2r}{D} \]

The section station \(r/R\) identifies the radial position of the selected two-dimensional blade profile, where \(R=D/2\).

Simulation Workflow

How the Solver Works

The simulation connects the user inputs, Django calculation backend, analytical charts, tabular output, and interactive three-dimensional geometry.

Inputs Blade Parameters

Select blade count \(Z\), expanded area ratio \(A_E/A_0\), pitch ratio \(P/D\), diameter \(D\), and radial section station \(r/R\).

Solver Django Backend

The selected parameters are posted to the numerical engine, which returns the full \(J\)-sweep containing \(K_T\), \(10K_Q\), and \(\eta_0\).

Geometry Table 6.8 Sections

The selected section station retrieves the corresponding face and back offsets required to construct the blade profile.

3D View Lofted Propeller Blade

The WebGL viewport lofts the returned section geometry across the radial stations and replicates the blade according to the selected blade count.

Output Charts and Numerical Data

Inspect the open-water curves, optimum efficiency point, section profile, and complete numerical data table.
